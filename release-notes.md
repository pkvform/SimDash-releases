
- Bridge сам проверяет новые версии на GitHub (при запуске и раз в 12 часов) и показывает карточку со списком изменений и кнопкой «Скачать». Проверку можно выключить в «Настройках».
- Исходники переехали в закрытый репозиторий, готовые версии публикуются в открытом `SimDash-releases`.
- Bridge checks GitHub for new versions (on start and every 12 hours) and shows a card with the changes and a Download button. The check can be switched off in Settings.
