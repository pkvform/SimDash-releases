Предварительная сборка SimDash 2.0 для Windows x64 и Waveshare ESP32-S3-Touch-LCD-1.69. В настройки Bridge и меню дисплея добавлен выбор «Автосимуляторы / Авиасимуляторы».

**Демо без платы.** Запустите EXE из отдельной папки, выберите «Настройки → Режим симулятора → Авиасимуляторы», затем «Демо». Листайте экраны в эмуляторе: PFD с авиагоризонтом, сводка MCDU, цели FCU и масса топлива на борту.

**Дисплей.** EXE содержит соответствующую прошивку. На дисплее откройте меню свайпом вниз и смените режим. Для возврата к гоночным экранам выберите «Авто».

**Источники.** Для MSFS 2020/2024 требуется оригинальный x64 SimConnect.dll из Microsoft Flight Simulator SDK рядом с EXE либо SDK в MSFS_SDK/MSFS2024_SDK. Для X-Plane используется локальный UDP 49000. Профиль A320ceo/neo читает общую телеметрию; доступность данных FMGS и целей FCU зависит от реализации самолёта. FCU работает в режиме чтения.

Собраны Bridge и прошивка. Пройдены программные тесты переключения, демо и UDP-обмена. Проверка на физическом дисплее и в кабине A320 каждого симулятора предстоит.
